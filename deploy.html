部署说明

用 GitHub 自动部署，不再手动上传 zip

这个站点已经推送到 GitHub 仓库。当前主发布地址使用 GitHub Pages，每次修改代码并推送到 main 分支，GitHub Actions 会自动发布新版页面。

GitHub Pages 设置

以 GitHub Pages 作为当前主发布地址

  1. 进入仓库设置打开 GitHub 仓库 coisini-AKF/AI，进入 Settings / Pages。
  2. 选择发布方式Source 选择 GitHub Actions，使用仓库里的 pages.yml 工作流部署。
  3. 推送 main 分支修改文件后提交并推送到 main，Actions 会自动发布。
  4. 验证线上页面访问 https://coisini-akf.github.io/AI/，确认首页和专题页是最新内容。

更新规则

以后更新网站只需要推送代码

本地改文件后执行提交和推送，GitHub Pages 会自动读取 GitHub main 分支并发布。当前项目是纯静态网站，不需要 npm install、build command 或后端服务器。
