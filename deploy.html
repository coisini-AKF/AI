部署说明

用 GitHub 自动部署，不再手动上传 zip

这个站点已经推送到 GitHub 仓库。把 Netlify 站点连接到该仓库后，每次修改代码并推送到 main 分支，Netlify 会自动发布新版页面。

Netlify 设置

一次绑定，后续自动更新

  1. 进入项目设置打开 Netlify 项目 shiny-belekoy-d2b680，进入 Deploys 或 Site configuration。
  2. 连接 GitHub选择 Link to Git repository 或 Import from Git，授权 GitHub。
  3. 选择仓库选择 coisini-AKF/AI，分支选择 main。
  4. 部署根目录Build command 留空，Publish directory 设置为 . 或保持默认根目录。

更新规则

以后更新网站只需要推送代码

本地改文件后执行提交和推送，Netlify 会自动读取 GitHub main 分支。当前项目是纯静态网站，不需要 npm install、build command 或后端服务器。
